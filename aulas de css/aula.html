Aula 1: O que é C++

C++ é uma linguagem compilada de alto desempenho, criada por Bjarne Stroustrup como evolução do C. Ela é usada em jogos, sistemas operacionais, navegadores, sistemas embarcados e onde velocidade importa.

Você escreve o código em um arquivo .cpp, o compilador (como o g++) o transforma em programa, e então você o executa:

#include <iostream>

int main() {
    std::cout << "Olá, mundo!" << std::endl;
    return 0;
}

Para compilar: g++ main.cpp -o programa

Exercício: como compilar e rodar o arquivo main.cpp?

Com g++ main.cpp -o programa e depois ./programa (no Windows, programa.exe).

Aula 2: Estrutura básica

Todo programa C++ começa a executar pela função main. As partes do esqueleto:

#include <iostream>
using namespace std;

int main() {
    cout << "Olá!" << endl;
    return 0;
}
  • #include importa bibliotecas (iostream cuida da entrada e saída).
  • using namespace std; evita escrever std:: toda hora.
  • main é o ponto de entrada; return 0 indica sucesso.
  • Toda instrução termina com ;.
Exercício: o que faz o #include?

Ele traz para o seu arquivo as declarações de uma biblioteca, como o iostream, que tem o cout.

Aula 3: Variáveis e tipos

Toda variável tem um tipo: int (inteiro), double (número com vírgula), char (um caractere), bool (verdadeiro ou falso) e std::string (texto, de <string>). Com auto o compilador descobre o tipo, e const impede que o valor mude.

int idade = 25;
double preco = 19.90;
std::string nome = "Ana";
bool ativo = true;
const double PI = 3.14159;
auto x = 10;
std::cout << nome << " tem " << idade << " anos\n";
Exercício: o que muda ao declarar uma variável com const?

O valor não pode mais ser alterado depois de definido.

Aula 4: Operadores e condições

Operadores aritméticos: + - * / %. Comparação: == != < > <= >=. Lógicos: && (e), || (ou) e ! (não).

int nota = 7;

if (nota >= 7) {
    std::cout << "Aprovado\n";
} else if (nota >= 5) {
    std::cout << "Recuperação\n";
} else {
    std::cout << "Reprovado\n";
}
Exercício: qual a diferença entre = e ==?

= atribui um valor; == compara dois valores.

Aula 5: Laços de repetição

Use for quando sabe quantas vezes repetir, while quando depende de uma condição e o for por faixa (for (x : colecao)) para percorrer todos os itens.

for (int i = 1; i <= 3; i++) {
    std::cout << i << "\n";
}

int n = 3;
while (n > 0) {
    n--;
}

std::string s = "C++";
for (char c : s) {
    std::cout << c << "\n";
}
Exercício: qual laço percorre todos os itens de uma coleção?

O for por faixa: for (auto x : colecao).

Aula 6: Funções, referências e ponteiros

Uma função tem tipo de retorno, nome e parâmetros; void não devolve nada. Com & no parâmetro, a função altera o original (referência). Um ponteiro (int*) guarda o endereço de uma variável: & pega o endereço e * acessa o valor apontado.

int somar(int a, int b) {
    return a + b;
}

void dobrar(int& x) {
    x *= 2;
}

int valor = somar(2, 3);   // 5
dobrar(valor);             // 10

int* p = &valor;
*p = 20;                   // valor agora é 20
Exercício: o que o & em int& x faz?

Passa o parâmetro por referência: a função altera a variável original, não uma cópia.

Aula 7: Classes e objetos

A classe é o molde; o objeto é criado a partir dele. O construtor tem o nome da classe e roda na criação. Em public ficam os membros acessíveis de fora e em private os protegidos.

class Pessoa {
public:
    std::string nome;

    Pessoa(std::string n) : nome(n) {}

    void falar() {
        std::cout << "Oi, sou " << nome << "\n";
    }
};

int main() {
    Pessoa p("Ana");
    p.falar();
}
Exercício: para que serve o construtor?

Para preparar o objeto no momento em que ele é criado.

Aula 8: Vetores e STL

A STL (biblioteca padrão) traz estruturas e algoritmos prontos. O std::vector é um array que cresce sozinho, e std::sort (de <algorithm>) ordena.

#include <vector>
#include <algorithm>

std::vector<int> nums = {5, 2, 8, 1};
nums.push_back(10);

std::sort(nums.begin(), nums.end());

for (int x : nums) {
    std::cout << x << " ";
}
Exercício: qual a vantagem do vector sobre um array comum?

Ele muda de tamanho (push_back) e sabe o próprio tamanho (size()).
