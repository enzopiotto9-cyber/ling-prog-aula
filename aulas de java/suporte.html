Dúvidas frequentes

Por onde eu começo?

Comece pela Aula 1 e siga a ordem. Cada aula tem exemplos de código e um exercício no final.

Preciso instalar algum programa?

O JDK (por exemplo, o Temurin ou o OpenJDK) e um editor, como o VS Code ou o IntelliJ IDEA. Depois, no terminal, rode javac Main.java e java Main.

O terminal diz que "javac" não é reconhecido.

Você instalou só o JRE ou o JDK não está no PATH. Instale o JDK, reabra o terminal e teste com javac -version.

Recebi o erro "class X is public, should be declared in file named X.java".

O nome do arquivo precisa ser igual ao da classe pública. A classe Main deve estar em Main.java, com as mesmas maiúsculas.

O que é NullPointerException?

Você usou um objeto que vale null (ainda não foi criado com new). Confira se a variável foi inicializada antes de usá-la.

Como peço um serviço, como monitoria?

Escolha na página de Serviços e envie uma mensagem aqui com o assunto "Solicitar um serviço".

Onde vejo os dias e horários das aulas?

Na página de Horários, que mostra a grade da semana e a próxima aula.
