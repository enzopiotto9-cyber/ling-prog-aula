Aula 1: O que é C#

C# (lê-se "C sharp") é uma linguagem moderna, fortemente tipada e orientada a objetos, criada pela Microsoft sob a liderança de Anders Hejlsberg. Ela roda sobre a plataforma .NET e é usada em sites e APIs (ASP.NET), aplicativos desktop, jogos (Unity), aplicativos móveis e serviços em nuvem.

Você escreve o código em um arquivo .cs, o SDK do .NET o compila e executa. Tudo pode ser feito pela linha de comando com a ferramenta dotnet:

dotnet new console -n MeuApp
cd MeuApp
dotnet run

O projeto nasce com um programa pronto. Nas versões recentes, basta uma linha:

Console.WriteLine("Olá, mundo!");
Exercício: qual comando cria e qual comando roda um projeto de console?

Crie com dotnet new console -n MeuApp e rode, dentro da pasta do projeto, com dotnet run.

Aula 2: Estrutura básica

Todo programa C# começa a executar pelo método Main. A forma completa, que aparece em muitos livros e projetos, é esta:

using System;

namespace MeuApp;

class Program
{
    static void Main()
    {
        Console.WriteLine("Olá!");
    }
}
  • using importa um namespace (System tem o Console).
  • namespace agrupa e organiza as suas classes.
  • class Program guarda o código; em C# tudo vive dentro de tipos.
  • Main é o ponto de entrada do programa.
  • Toda instrução termina com ;.

Desde o C# 9, as instruções de nível superior permitem escrever só Console.WriteLine("Olá!");, e o compilador cria o Main para você. Neste curso usamos essa forma curta nos exemplos.

Exercício: o que faz o using System;?

Ele traz para o seu arquivo os tipos do namespace System, como o Console, sem precisar escrever System.Console toda vez.

Aula 3: Variáveis e tipos

Toda variável tem um tipo: int (inteiro), double (número com vírgula), decimal (dinheiro, com precisão), char (um caractere), bool (verdadeiro ou falso) e string (texto). Com var o compilador descobre o tipo, e const impede que o valor mude.

int idade = 25;
double altura = 1.75;
decimal preco = 19.90m;
string nome = "Ana";
bool ativo = true;
const double Pi = 3.14159;
var x = 10;
Console.WriteLine($"{nome} tem {idade} anos");

O $"..." é a interpolação de texto: o que está entre chaves é substituído pelo valor da variável.

Exercício: por que usar decimal em vez de double para preços?

O decimal guarda números decimais com exatidão, sem os pequenos erros de arredondamento que o double pode ter.

Aula 4: Operadores e condições

Operadores aritméticos: + - * / %. Comparação: == != < > <= >=. Lógicos: && (e), || (ou) e ! (não).

int nota = 7;

if (nota >= 7)
{
    Console.WriteLine("Aprovado");
}
else if (nota >= 5)
{
    Console.WriteLine("Recuperação");
}
else
{
    Console.WriteLine("Reprovado");
}

string situacao = nota switch
{
    >= 7 => "Aprovado",
    >= 5 => "Recuperação",
    _ => "Reprovado"
};

O switch como expressão devolve um valor, e o _ cobre todos os demais casos.

Exercício: qual a diferença entre = e ==?

= atribui um valor; == compara dois valores.

Aula 5: Laços de repetição

Use for quando sabe quantas vezes repetir, while quando depende de uma condição e foreach para percorrer todos os itens de uma coleção.

for (int i = 1; i <= 3; i++)
{
    Console.WriteLine(i);
}

int n = 3;
while (n > 0)
{
    n--;
}

string s = "C#";
foreach (char c in s)
{
    Console.WriteLine(c);
}
Exercício: qual laço percorre todos os itens de uma coleção?

O foreach: foreach (var x in colecao).

Aula 6: Métodos, ref e out

Um método tem tipo de retorno, nome e parâmetros; void não devolve nada. Por padrão, os valores são copiados para o método. Com ref, o método altera a variável original. Com out, ele devolve um valor extra por um parâmetro.

static int Somar(int a, int b)
{
    return a + b;
}

static void Dobrar(ref int x)
{
    x *= 2;
}

static bool TentarDividir(int a, int b, out int resultado)
{
    resultado = 0;
    if (b == 0) return false;
    resultado = a / b;
    return true;
}

int valor = Somar(2, 3);   // 5
Dobrar(ref valor);         // 10

if (TentarDividir(10, 2, out int r))
{
    Console.WriteLine(r);  // 5
}

Em C# você raramente precisa de ponteiros: as classes já são passadas por referência, e o coletor de lixo cuida da memória.

Exercício: o que o ref em ref int x faz?

Passa o parâmetro por referência: o método altera a variável original, não uma cópia.

Aula 7: Classes e objetos

A classe é o molde; o objeto é criado a partir dele com new. O construtor tem o nome da classe e roda na criação. Em public ficam os membros acessíveis de fora e em private os protegidos. Uma propriedade ({ get; set; }) controla o acesso a um dado.

Pessoa p = new Pessoa("Ana");
p.Falar();

class Pessoa
{
    public string Nome { get; }

    public Pessoa(string nome)
    {
        Nome = nome;
    }

    public void Falar()
    {
        Console.WriteLine($"Oi, sou {Nome}");
    }
}

Com instruções de nível superior, o código do programa vem primeiro e as classes vêm depois, no mesmo arquivo.

Exercício: para que serve o construtor?

Para preparar o objeto no momento em que ele é criado.

Aula 8: Coleções e LINQ

As coleções do .NET trazem estruturas prontas. A List<T> é uma lista que cresce sozinha, e o LINQ (System.Linq) consulta e transforma coleções com métodos como Where e Select.

var nums = new List<int> { 5, 2, 8, 1 };
nums.Add(10);
nums.Sort();

foreach (int x in nums)
{
    Console.Write(x + " ");
}

var pares = nums.Where(n => n % 2 == 0).ToList();
var dobros = nums.Select(n => n * 2).ToList();

Nos projetos novos, System, System.Collections.Generic e System.Linq já vêm importados automaticamente (implicit usings).

Exercício: qual a vantagem da List<T> sobre um array comum?

Ela muda de tamanho (Add, Remove) e sabe o próprio tamanho (Count).
