Aula 1: O que é PHP

PHP é uma linguagem de servidor: o código roda no servidor e o visitante recebe só o HTML pronto. É a base de sites dinâmicos, de sistemas como o WordPress e de frameworks como o Laravel.

O código fica em arquivos .php, dentro das tags <?php ... ?>. Para testar, instale o PHP e rode no terminal php -S localhost:8000:

<?php
echo "Olá, mundo!";
Exercício: onde o código PHP é executado?

No servidor. O navegador recebe apenas o resultado, em HTML.

Aula 2: Estrutura básica

O PHP pode ser misturado ao HTML. Tudo fora das tags <?php ?> é enviado como está, e cada instrução termina com ;. O echo escreve na página, e <?= ... ?> é um atalho para ele.

<!DOCTYPE html>
<html>
<body>
    <h1><?php echo "Olá!"; ?></h1>
    <p>Hoje é <?= date("d/m/Y") ?></p>
</body>
</html>
Exercício: o que faz <?= $nome ?>?

É um atalho para <?php echo $nome; ?>: escreve o valor na página.

Aula 3: Variáveis e tipos

Toda variável começa com $ e não precisa declarar o tipo. Os tipos comuns são string, int, float, bool, array e null. Aspas duplas inserem variáveis no texto, e o ponto (.) junta textos.

$nome = "Ana";
$idade = 25;
$preco = 19.90;
$ativo = true;

echo "$nome tem $idade anos\n";
echo "Preço: " . $preco;
Exercício: com qual símbolo começa o nome de uma variável?

Com $, como em $nome.

Aula 4: Operadores e condições

Operadores aritméticos: + - * / %. Lógicos: &&, || e !. Prefira === (compara valor e tipo) a ==, que converte os tipos sozinho.

$nota = 7;

if ($nota >= 7) {
    echo "Aprovado";
} elseif ($nota >= 5) {
    echo "Recuperação";
} else {
    echo "Reprovado";
}
Exercício: por que usar === em vez de ==?

Porque ele compara valor e tipo, evitando conversões inesperadas.

Aula 5: Laços de repetição

Use for quando sabe o número de voltas, while quando depende de uma condição e foreach para percorrer arrays.

for ($i = 1; $i <= 3; $i++) {
    echo $i . "\n";
}

$n = 3;
while ($n > 0) {
    $n--;
}

foreach (["maçã", "uva"] as $fruta) {
    echo $fruta . "\n";
}
Exercício: qual laço percorre todos os itens de um array?

O foreach.

Aula 6: Funções

Funções agrupam código reutilizável. Você pode indicar o tipo dos parâmetros e do retorno, e return devolve o resultado.

function somar(int $a, int $b): int {
    return $a + $b;
}

echo somar(2, 3);
Exercício: o que faz o return?

Devolve um valor para quem chamou a função e encerra a execução dela.

Aula 7: Arrays

Um array guarda vários valores. Com chaves de texto, vira um array associativo (chave => valor). Funções úteis: count, in_array e array_push.

$frutas = ["maçã", "uva"];
$frutas[] = "pera";

$pessoa = ["nome" => "Ana", "idade" => 25];

foreach ($pessoa as $chave => $valor) {
    echo "$chave: $valor\n";
}

echo count($frutas);
Exercício: como adicionar um item ao fim de um array?

Com $array[] = valor; ou array_push($array, valor).

Aula 8: Formulários

O PHP recebe os dados de formulários em $_POST (método post) e $_GET (dados na URL). Nunca escreva dados do usuário direto na página: use htmlspecialchars para evitar ataques XSS.

<form method="post">
    <input name="nome">
    <button>Enviar</button>
</form>

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $nome = htmlspecialchars($_POST["nome"]);
    echo "Olá, $nome!";
}
Exercício: para que serve o htmlspecialchars?

Converte caracteres especiais (como <) em texto seguro, evitando que o usuário injete código na página (XSS).
