Aula 1: O que é design

Design é organizar forma, cor e informação para que algo seja fácil de entender e agradável de usar. Não é só deixar bonito: um bom design resolve um problema de alguém.

Antes de desenhar, responda: para quem é? qual é a mensagem? o que deve ser visto primeiro? Depois aplique os quatro princípios básicos, que você vai ver em todas as aulas:

  • Proximidade: o que é parecido fica junto.
  • Alinhamento: cada elemento se prende a uma linha invisível.
  • Repetição: cores, fontes e formas se repetem para criar identidade.
  • Contraste: o que é importante se diferencia do resto.
Exercício: qual pergunta vem antes de desenhar qualquer coisa?

Para quem é e qual problema a peça precisa resolver.

Aula 2: Cor e paleta

Uma paleta simples funciona melhor que muitas cores soltas. A regra 60-30-10 ajuda: 60% de uma cor de fundo, 30% de uma cor de apoio e 10% de uma cor de destaque.

No site, guarde as cores em variáveis e troque a paleta inteira mudando só um lugar:

:root {
  --fundo: #f3edff;    /* 60% */
  --apoio: #6d28d9;    /* 30% */
  --destaque: #ffb800; /* 10% */
}
Exercício: por que limitar o destaque a cerca de 10%?

Porque o que aparece pouco chama atenção. Se tudo é destaque, nada é.

Aula 3: Tipografia

A fonte dá a voz do design. Use no máximo duas famílias: uma para títulos e outra para o texto. A hierarquia nasce da variação de tamanho, peso e cor.

Para ler bem, mantenha linhas com 45 a 75 caracteres e um espaço entre linhas de cerca de 1,5 vez o tamanho da letra.

h1 { font-size: 2.4rem; line-height: 1.1; }
p  { font-size: 1rem; line-height: 1.6; max-width: 65ch; }
Exercício: quantas famílias de fonte usar em uma peça?

Até duas. Varie tamanho e peso para criar hierarquia em vez de trocar de fonte.

Aula 4: Alinhamento e espaço

Alinhe tudo a uma linha em comum e use espaços que seguem uma escala, como múltiplos de 8 (8, 16, 24, 32). O espaço em branco não é desperdício: ele separa ideias e dá ritmo.

Coloque perto o que tem relação e longe o que não tem. Isso se chama proximidade.

.cartao { padding: 24px; }
.cartao > * + * { margin-top: 16px; }
Exercício: por que usar espaços em múltiplos de 8?

Porque criam um ritmo consistente e facilitam alinhar e dividir as medidas.

Aula 5: Contraste e hierarquia

Contraste é a diferença entre dois elementos: claro e escuro, grande e pequeno, cheio e vazio. É ele que mostra o que importa. Para texto comum, a razão mínima entre texto e fundo é 4,5 para 1 (WCAG AA).

Faça o teste de apertar os olhos: se a informação principal some quando a imagem fica embaçada, falta hierarquia.

.botao-principal {
  background: #2e1065;
  color: #fff; /* contraste alto */
}
Exercício: qual é a razão mínima de contraste para texto comum?

4,5 para 1, segundo o nível AA do WCAG.

Aula 6: Composição e grade

Composição é onde cada coisa fica na página. Duas ferramentas simples: a regra dos terços, que divide a área em nove partes e coloca o ponto principal em um dos quatro cruzamentos, e a grade de colunas, que mantém o layout organizado.

.grade { display: grid; grid-template-columns: repeat(12, 1fr); gap: 16px; }
.destaque { grid-column: span 8; }
Exercício: onde colocar o ponto principal na regra dos terços?

Em um dos quatro cruzamentos das linhas, em vez de no centro.

Aula 7: Formas e ícones

Círculo, quadrado e triângulo são a base de quase todo ícone e logotipo. Cada forma passa uma sensação: o círculo é suave, o quadrado é estável e o triângulo é dinâmico.

Mantenha o conjunto coerente: mesma espessura de traço, mesmo tipo de canto e mesmo estilo em todos os ícones.

.circulo   { border-radius: 50%; }
.triangulo { clip-path: polygon(50% 0, 0 100%, 100% 100%); }
Exercício: quais formas básicas formam quase todo ícone?

Círculo, quadrado e triângulo, combinados e ajustados.

Aula 8: Movimento

Animação boa tem propósito: mostrar o que mudou ou guiar o olhar. Use de 150 a 400 milissegundos e prefira animar transform e opacity. A curva de aceleração muda a sensação: ease-out parece natural para algo que entra na tela.

Respeite quem prefere menos movimento, como o site faz na opção de acessibilidade.

.botao { transition: transform .2s ease-out; }
.botao:hover { transform: translateY(-2px); }

@media (prefers-reduced-motion: reduce) {
  .botao { transition: none; }
}
Exercício: qual curva dá sensação natural a algo que entra na tela?

A ease-out: começa rápida e desacelera até parar.
