Aula 1: O que é CSS

CSS (Cascading Style Sheets) é a linguagem que dá aparência à página: cores, fontes, espaços e layout. O HTML cria a estrutura; o CSS decide como ela é mostrada.

Uma regra tem três partes: o seletor (quem recebe o estilo), a propriedade (o que muda) e o valor (como muda):

p {
  color: blue;        /* propriedade: valor; */
  font-size: 18px;
}

O jeito mais comum de usar é um arquivo .css ligado no <head> do HTML:

<link rel="stylesheet" href="style.css">
Exercício: como ligar um arquivo style.css à página?

Com a tag <link rel="stylesheet" href="style.css"> dentro do <head>.

Aula 2: Seletores

Seletores apontam os elementos. Os principais: p (tag), .classe, #id, nav a (descendente), ul > li (filho direto) e pseudo-classes como :hover.

p { color: #333; }              /* todas as tags p */
.destaque { color: crimson; }   /* class="destaque" */
#topo { background: navy; }     /* id="topo" */
nav a { text-decoration: none; }
ul > li { list-style: square; }
a:hover { color: orange; }
h1, h2, h3 { font-family: serif; } /* grupo */

Quando duas regras brigam, vence a mais específica: id > classe > tag. Se empatar, vale a que vem por último.

Exercício: qual seletor escolhe todos os elementos com class="card"?

.card, com um ponto antes do nome da classe.

Aula 3: Cores e texto

Cores podem ser nomes (tomato), hexadecimais (#ff6347), rgb() ou hsl(). Para texto: font-family, font-size, font-weight, line-height e text-align.

body {
  font-family: system-ui, sans-serif;
  font-size: 18px;
  line-height: 1.6;        /* espaço entre linhas */
  color: #1f2937;
  background: #f8fafc;
}
h1 {
  color: hsl(210, 80%, 40%);
  text-align: center;
}

Exercício: o que faz line-height: 1.6?

Define a altura da linha como 1,6 vez o tamanho da fonte, deixando o texto mais arejado.

Aula 4: Modelo de caixa

Todo elemento é uma caixa com quatro camadas: conteúdo, padding (espaço interno), border (borda) e margin (espaço externo). Use box-sizing: border-box para que a largura já inclua padding e borda.

* { box-sizing: border-box; }

.caixa {
  width: 300px;
  padding: 20px;               /* dentro */
  border: 3px solid #00599c;
  margin: 16px auto;           /* fora; auto centraliza */
  border-radius: 12px;
}

Exercício: qual a diferença entre margin e padding?

padding é o espaço dentro da borda; margin é o espaço fora dela, entre elementos.

Aula 5: Flexbox

Com display: flex no pai, os filhos ficam em linha ou coluna. justify-content alinha no eixo principal, align-items no eixo cruzado e gap cria espaço entre os itens.

.menu {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Veja funcionando

123
Exercício: como centralizar um item na horizontal e na vertical com flex?

No pai: display: flex; justify-content: center; align-items: center;.

Aula 6: Grid

O Grid organiza em duas dimensões. Defina colunas com grid-template-columns; a unidade fr divide o espaço livre. Com repeat(auto-fit, minmax()) o layout se adapta sozinho à largura.

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
  gap: 12px;
}

Duas colunas: a segunda ocupa o dobro do espaço da primeira.

Aula 7: Posicionamento e responsividade

Com position você tira elementos do fluxo: relative (referência), absolute (relativo ao pai posicionado), fixed (fixo na tela) e sticky (gruda ao rolar). Para adaptar a telas diferentes use @media.

.cartao { position: relative; }
.selo {
  position: absolute;
  top: 8px;
  right: 8px;
}

.menu { position: sticky; top: 0; }

.colunas { display: grid; grid-template-columns: 1fr; }
@media (min-width: 768px) {
  .colunas { grid-template-columns: 1fr 1fr; }
}

Dica: comece pensando no celular (mobile first) e acrescente regras para telas maiores.

Exercício: o que o @media (min-width: 768px) faz?

Aplica as regras de dentro apenas quando a tela tem 768px de largura ou mais.

Aula 8: Transições, animações e variáveis

transition suaviza a mudança entre estados, como no :hover. Para animações em loop use @keyframes com animation. E com variáveis (--nome) você troca a paleta inteira mudando um só lugar.

:root {
  --cor: #00599c;
}
.botao {
  background: var(--cor);
  transition: transform .25s, background .25s;
}
.botao:hover {
  transform: translateY(-4px) scale(1.06);
  background: #ff3d81;
}

@keyframes ida {
  to { left: calc(100% - 36px); }
}
.bola { animation: ida 2.4s ease-in-out infinite alternate; }

Veja funcionando

Exercício: para que serve var(--cor)?

Usa o valor da variável --cor, definida em :root; mudando-a, tudo que a usa muda junto.
