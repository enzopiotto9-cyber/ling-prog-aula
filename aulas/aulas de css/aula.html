Aula 1: O que é C++

C++ é uma linguagem compilada de alto desempenho, criada por Bjarne Stroustrup como evolução do C. Ela está em jogos, sistemas operacionais, navegadores, bancos de dados e sistemas embarcados: onde velocidade e controle importam.

Você escreve o código em um arquivo .cpp, o compilador (como o g++) o transforma em programa, e então você o executa:

#include <iostream>

int main() {
    std::cout << "Olá, mundo!" << std::endl;
    return 0;
}

Para compilar: g++ main.cpp -o programa. Mas o que o g++ faz por dentro? Veja as etapas (a animação roda sozinha):

Dica: use -std=c++20 para ligar os recursos modernos: g++ -std=c++20 main.cpp -o programa.

Exercício: como compilar e rodar o arquivo main.cpp?

Com g++ main.cpp -o programa e depois ./programa (no Windows, programa.exe).

Aula 2: Estrutura básica

Todo programa C++ começa a executar pela função main. As partes do esqueleto:

#include <iostream>
using namespace std;

// comentário de uma linha
/* comentário
   de várias linhas */
int main() {
    cout << "Olá!" << endl;
    return 0;
}
  • #include importa bibliotecas (iostream cuida da entrada e saída).
  • using namespace std; evita escrever std:: toda hora.
  • main é o ponto de entrada; return 0 indica sucesso.
  • Toda instrução termina com ;.

Atenção: esquecer o ; é o erro mais comum. O compilador costuma apontar a linha seguinte à do problema.

Exercício: o que faz o #include?

Ele traz para o seu arquivo as declarações de uma biblioteca, como o iostream, que tem o cout.

Aula 4: Entrada e saída

cout escreve na tela com <<; cin lê do teclado com >>. Para ler uma linha inteira (com espaços) use getline.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nome;
    int idade;

    cout << "Seu nome: ";
    getline(cin, nome);
    cout << "Sua idade: ";
    cin >> idade;

    cout << "Olá, " << nome << "! Ano que vem você terá " << idade + 1 << ".\n";
}

Pegadinha: depois de um cin >> sobra um \n no buffer e o próximo getline lê uma linha vazia. Resolva com cin.ignore();.

Exercício: por que usar getline em vez de cin >> para ler um nome completo?

cin >> para no primeiro espaço; getline lê a linha inteira.

Aula 5: Operadores

Aritméticos: + - * / %. Compostos: += -= *= /=, além de ++ e --. Comparação: == != < > <= >=. Lógicos: && (e), || (ou) e ! (não).

int a = 7, b = 2;
std::cout << a / b << "\n";     // 3   (divisão inteira)
std::cout << a % b << "\n";     // 1   (resto)
std::cout << a / 2.0 << "\n";   // 3.5

int c = 5;
c += 3;                         // c = c + 3  ->  8
c++;                            // 9

bool ok = (a > b) && !(b == 0); // true

Atenção: divisão entre dois inteiros descarta a parte decimal. Para ter decimais, pelo menos um dos lados precisa ser double.

Exercício: quanto vale 7 / 2 com inteiros? E 7 / 2.0?

3 e 3.5.

Aula 6: Condições: if e else

O if executa um bloco só quando a condição é verdadeira. Encadeie com else if e else.

int nota = 7;

if (nota >= 7) {
    std::cout << "Aprovado\n";
} else if (nota >= 5) {
    std::cout << "Recuperação\n";
} else {
    std::cout << "Reprovado\n";
}

Cuidado: if (x = 5) atribui 5 a x e é sempre verdadeiro. Para comparar, use ==.

Exercício: qual a diferença entre = e ==?

= atribui um valor; == compara dois valores.

Aula 7: switch e operador ternário

Quando há muitos casos para um mesmo valor, o switch fica mais limpo que vários else if. O operador ternário cond ? a : b é um if/else em uma linha.

int dia = 3;
switch (dia) {
    case 1: std::cout << "Domingo\n"; break;
    case 2: std::cout << "Segunda\n"; break;
    case 3: std::cout << "Terça\n";   break;
    default: std::cout << "Outro dia\n";
}

int idade = 20;
std::string tipo = (idade >= 18) ? "adulto" : "menor";

Atenção: sem break, a execução "cai" para o próximo case (fall-through).

Exercício: o que acontece se esquecer o break em um case?

A execução continua no case seguinte até achar um break ou o fim do switch.

Aula 8: Laços de repetição

Use for quando sabe quantas vezes repetir, while quando depende de uma condição, do-while quando precisa executar ao menos uma vez e o for por faixa para percorrer todos os itens.

for (int i = 1; i <= 3; i++) {
    std::cout << i << "\n";
}

int n = 3;
while (n > 0) {
    n--;
}

int tentativa;
do {
    std::cout << "Digite um número positivo: ";
    std::cin >> tentativa;
} while (tentativa <= 0);

std::string s = "C++";
for (char c : s) {
    std::cout << c << "\n";
}
Exercício: qual laço percorre todos os itens de uma coleção?

O for por faixa: for (auto x : colecao).

Aula 9: break, continue e laços aninhados

continue pula o resto da volta atual; break encerra o laço inteiro. Um laço dentro de outro (aninhado) é ótimo para tabelas e desenhos.

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // pula os pares
    if (i > 7) break;           // para ao chegar no 9
    std::cout << i << " ";      // 1 3 5 7
}

for (int linha = 1; linha <= 3; linha++) {
    for (int col = 1; col <= linha; col++) {
        std::cout << "*";
    }
    std::cout << "\n";
}

Resultado do segundo laço: um triângulo de * com 1, 2 e 3 estrelas por linha.

Exercício: o que continue faz dentro de um laço?

Pula o resto da volta atual e vai para a próxima iteração; já o break encerra o laço inteiro.

Aula 10: Funções

Uma função tem tipo de retorno, nome e parâmetros; void não devolve nada. Você pode declarar o protótipo antes, dar valores padrão aos parâmetros e criar versões com o mesmo nome e parâmetros diferentes (sobrecarga).

#include <iostream>
#include <string>

int somar(int a, int b);                       // protótipo

double area(double lado) { return lado * lado; }
double area(double base, double altura) {      // sobrecarga
    return base * altura / 2;
}

void saudar(std::string nome = "visitante") {  // valor padrão
    std::cout << "Olá, " << nome << "\n";
}

int main() {
    std::cout << somar(2, 3) << "\n";                   // 5
    std::cout << area(4) << " " << area(3, 5) << "\n";  // 16 7.5
    saudar();
    saudar("Ana");
}

int somar(int a, int b) { return a + b; }
Exercício: para que serve o protótipo de uma função?

Avisa o compilador que a função existe antes de ela ser definida, permitindo usá-la acima da definição.

Aula 11: Escopo e a pilha (stack)

Uma variável só existe dentro do bloco { } onde foi criada. Cada chamada de função cria um quadro na pilha (stack) com suas variáveis locais, e ao retornar ele é destruído. Variáveis static locais, porém, sobrevivem entre as chamadas.

int global = 100;               // vive o programa inteiro

void contar() {
    static int vezes = 0;       // criada uma vez só
    int local = 0;              // criada a cada chamada
    vezes++; local++;
    std::cout << vezes << " " << local << "\n";
}

int main() {
    contar();   // 1 1
    contar();   // 2 1
    {
        int x = 5;              // só existe neste bloco
    }
    // std::cout << x;          // ERRO: x não existe aqui
}
Exercício: qual a diferença entre uma variável local e uma static local?

A local é recriada a cada chamada; a static é criada uma vez e mantém o valor entre as chamadas.

Aula 12: Referências

Com & no parâmetro, a função altera o original (passagem por referência). Use const & para ler objetos grandes sem copiá-los. Uma referência também pode ser um apelido para uma variável.

void dobrar(int& x) { x *= 2; }           // altera o original

void mostrar(const std::string& s) {      // sem cópia, sem alterar
    std::cout << s << "\n";
}

void trocar(int& a, int& b) {
    int t = a; a = b; b = t;
}

int main() {
    int v = 5;
    dobrar(v);            // v = 10
    int a = 1, b = 2;
    trocar(a, b);         // a = 2, b = 1
    mostrar("C++");

    int& r = v;           // r é outro nome para v
    r = 99;               // v agora vale 99
}

Veja na memória: r não é uma cópia, é a mesma caixa de a.

Exercício: o que o & em int& x faz?

Passa o parâmetro por referência: a função altera a variável original, não uma cópia.

Aula 13: Ponteiros

Um ponteiro (int*) guarda o endereço de uma variável. & pega o endereço e * acessa o valor apontado. nullptr significa "não aponta para nada".

int x = 10;
int* p = &x;          // p guarda o endereço de x
std::cout << *p;      // 10   (* acessa o valor apontado)
*p = 20;              // x agora vale 20
std::cout << p;       // imprime o endereço, ex.: 0x7ffc...

int v[3] = {1, 2, 3};
int* q = v;           // aponta para o primeiro elemento
std::cout << *(q + 1);   // 2  (aritmética de ponteiros)
p = nullptr;          // não aponta para nada

Execute passo a passo e veja a memória mudar:

Nunca desreferencie um nullptr (*p com p nulo): o programa quebra.

Exercício: o que & e * fazem com ponteiros?

&x pega o endereço de x; *p acessa o valor guardado no endereço que p aponta.

Aula 14: Arrays

Um array guarda elementos do mesmo tipo lado a lado na memória. O primeiro índice é 0. O std::array é a versão moderna: sabe o próprio tamanho.

#include <array>
#include <iostream>

int main() {
    int notas[5] = {7, 8, 5, 10, 9};
    int soma = 0;
    for (int i = 0; i < 5; i++) soma += notas[i];
    std::cout << "Média: " << soma / 5.0 << "\n";   // 7.8

    std::array<int, 3> a = {1, 2, 3};
    std::cout << a.size() << "\n";                  // 3

    // notas[10] = 1;   // PERIGO: fora dos limites
}

Atenção: o operador [ ] não confere os limites. Acessar fora do array é comportamento indefinido. Com .at(i) você recebe uma exceção em vez de um bug silencioso.

Exercício: o que acontece ao acessar notas[10] em um array de 5 posições?

Comportamento indefinido: pode travar, ler lixo ou corromper memória, pois o C++ não checa limites com [ ].

Aula 15: Alocação dinâmica: new e delete

Variáveis comuns vivem na pilha e somem sozinhas. Com new você pede memória ao heap e ela só é liberada quando você chama delete (ou delete[] para arrays).

int* p = new int(42);        // aloca 1 int no heap
std::cout << *p << "\n";     // 42
delete p;                    // libera
p = nullptr;                 // evita ponteiro pendurado

int n = 3;
int* v = new int[n];         // array dinâmico
for (int i = 0; i < n; i++) v[i] = i * 10;
delete[] v;                  // delete[] para arrays

Vazamento (memory leak): esquecer o delete deixa a memória ocupada até o programa acabar. Na Aula 27 você verá os smart pointers, que liberam sozinhos.

Exercício: o que é um memory leak?

Memória alocada com new que nunca é liberada com delete, ficando ocupada sem uso até o fim do programa.

Aula 16: Classes e objetos

A classe é o molde; o objeto é criado a partir dele. O construtor tem o nome da classe e roda na criação. Em public ficam os membros acessíveis de fora e em private os protegidos.

class Pessoa {
public:
    std::string nome;

    Pessoa(std::string n) : nome(n) {}

    void falar() {
        std::cout << "Oi, sou " << nome << "\n";
    }
};

int main() {
    Pessoa p("Ana");
    p.falar();
}

Dica: struct é igual a class, só que os membros são public por padrão.

Exercício: qual a diferença entre classe e objeto?

A classe é o molde (a descrição); o objeto é uma instância concreta criada a partir dela.

Aula 17: Construtores e destrutores

O construtor prepara o objeto; o destrutor (~Nome) roda quando ele deixa de existir. Esse par é a base do idioma RAII: abrir um recurso no construtor e liberá-lo no destrutor.

class Arquivo {
    std::string nome;
public:
    Arquivo() : nome("sem nome") { std::cout << "criado: " << nome << "\n"; }
    Arquivo(std::string n) : nome(n) { std::cout << "criado: " << nome << "\n"; }
    ~Arquivo() { std::cout << "destruído: " << nome << "\n"; }
};

int main() {
    Arquivo a;               // criado: sem nome
    Arquivo b("dados.txt");  // criado: dados.txt
}   // ao sair do escopo: destruído b, depois destruído a

Repare: a lista : nome(n) é a lista de inicialização; ela inicializa o membro antes do corpo do construtor.

Exercício: quando o destrutor é chamado?

Automaticamente, quando o objeto sai do escopo (ou ao usar delete, se ele foi criado com new).

Aula 18: Encapsulamento e const

Deixe os atributos private e ofereça métodos públicos que validam as mudanças. Métodos marcados com const prometem não alterar o objeto.

class Conta {
private:
    double saldo = 0;
public:
    void depositar(double v) {
        if (v > 0) saldo += v;
    }
    bool sacar(double v) {
        if (v <= 0 || v > saldo) return false;
        saldo -= v;
        return true;
    }
    double getSaldo() const { return saldo; }   // const: não altera o objeto
};
Exercício: por que deixar saldo como private?

Para que ninguém altere o saldo diretamente: toda mudança passa por métodos que validam as regras (como não sacar mais do que existe).

Aula 19: Herança

Uma classe filha herda atributos e métodos da classe base com : public Base. Membros protected ficam visíveis para as filhas, mas não para o resto do programa.

class Animal {
protected:
    std::string nome;
public:
    Animal(std::string n) : nome(n) {}
    void comer() { std::cout << nome << " está comendo\n"; }
};

class Cachorro : public Animal {
public:
    Cachorro(std::string n) : Animal(n) {}   // chama o construtor da base
    void latir() { std::cout << nome << ": Au au!\n"; }
};

int main() {
    Cachorro rex("Rex");
    rex.comer();   // herdado de Animal
    rex.latir();
}
Exercício: o que significa class Cachorro : public Animal?

Que Cachorro herda de Animal: ganha seus membros públicos e protegidos e pode acrescentar os seus.

Aula 20: Polimorfismo e virtual

Com métodos virtual, uma chamada feita por ponteiro (ou referência) da classe base executa a versão da classe real do objeto. Um método = 0 é puro e torna a classe abstrata.

#include <iostream>
#include <vector>

class Forma {
public:
    virtual double area() const = 0;     // puro: classe abstrata
    virtual ~Forma() = default;
};

class Quadrado : public Forma {
    double lado;
public:
    Quadrado(double l) : lado(l) {}
    double area() const override { return lado * lado; }
};

class Circulo : public Forma {
    double r;
public:
    Circulo(double raio) : r(raio) {}
    double area() const override { return 3.14159 * r * r; }
};

int main() {
    std::vector<Forma*> formas = { new Quadrado(2), new Circulo(1) };
    for (Forma* f : formas) {
        std::cout << f->area() << "\n";   // cada objeto usa a sua versão
        delete f;
    }
}

Dica: f->area() equivale a (*f).area(). E o destrutor da base precisa ser virtual para o delete funcionar direito.

Exercício: para que serve a palavra virtual?

Permite que a chamada por ponteiro ou referência da base execute a versão da classe real do objeto (ligação dinâmica).

Aula 21: Sobrecarga de operadores

Você pode redefinir operadores para os seus tipos, fazendo a + b funcionar com objetos. O operator<< permite usar o cout direto com eles.

#include <iostream>

struct Vetor {
    double x, y;
    Vetor operator+(const Vetor& o) const { return {x + o.x, y + o.y}; }
    bool operator==(const Vetor& o) const { return x == o.x && y == o.y; }
};

std::ostream& operator<<(std::ostream& os, const Vetor& v) {
    return os << "(" << v.x << ", " << v.y << ")";
}

int main() {
    Vetor a{1, 2}, b{3, 4};
    std::cout << a + b << "\n";    // (4, 6)
}
Exercício: por que operator<< devolve um std::ostream&?

Para permitir o encadeamento: cout << a << b usa o retorno de cada << como entrada do próximo.

Aula 22: std::vector

O std::vector é o contêiner mais usado do C++: guarda elementos em sequência, cresce conforme necessário e sabe o próprio tamanho.

#include <iostream>
#include <vector>

int main() {
    std::vector<int> nums = {5, 2, 8};
    nums.push_back(10);            // {5, 2, 8, 10}
    nums.insert(nums.begin(), 1);  // {1, 5, 2, 8, 10}
    nums.pop_back();               // {1, 5, 2, 8}
    nums.erase(nums.begin());      // {5, 2, 8}

    std::cout << nums.size() << " " << nums.at(0) << "\n";   // 3 5
    for (int x : nums) std::cout << x << " ";                // 5 2 8

    std::vector<std::vector<int>> grade(3, std::vector<int>(3, 0));  // matriz 3x3
}
Exercício: qual a vantagem do vector sobre um array comum?

Ele muda de tamanho (push_back) e sabe o próprio tamanho (size()).

Aula 23: std::string

A std::string cuida da memória do texto sozinha e traz métodos prontos para medir, cortar, procurar e converter.

std::string s = "Aprenda C++";
std::cout << s.length() << "\n";          // 11
std::cout << s.substr(0, 7) << "\n";      // Aprenda
std::cout << s.find("C++") << "\n";       // 8
s += "!";                                 // concatenar
s[0] = 'a';                               // acessar um caractere

int n = std::stoi("42");                  // texto -> int
std::string t = std::to_string(3.5);      // número -> texto
Exercício: como converter o texto "42" em um número inteiro?

Com std::stoi("42").

Aula 24: map e set

O std::map guarda pares chave → valor ordenados pela chave. O std::set guarda valores únicos, também ordenados.

#include <iostream>
#include <map>
#include <set>
#include <string>

int main() {
    std::map<std::string, int> idades = {{"Ana", 25}, {"Beto", 30}};
    idades["Carla"] = 22;                       // insere ou atualiza
    if (idades.count("Ana")) std::cout << idades["Ana"] << "\n";

    for (const auto& [nome, idade] : idades)    // C++17: desestruturação
        std::cout << nome << ": " << idade << "\n";

    std::set<int> unicos = {3, 1, 3, 2, 1};     // guarda {1, 2, 3}
    std::cout << unicos.size() << "\n";         // 3
}

Dica: std::unordered_map e std::unordered_set não ordenam, mas costumam ser mais rápidos para buscar.

Exercício: qual a diferença entre map e set?

map guarda pares chave → valor; set guarda apenas valores únicos. Ambos mantêm a ordem.

Aula 25: Algoritmos e iteradores

Iteradores são "setas" que percorrem um contêiner. Os algoritmos de <algorithm> trabalham com eles: begin() aponta para o primeiro elemento e end() para uma posição depois do último.

#include <algorithm>
#include <functional>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> v = {5, 2, 8, 1};

    std::sort(v.begin(), v.end());                 // 1 2 5 8
    std::reverse(v.begin(), v.end());              // 8 5 2 1
    auto it = std::find(v.begin(), v.end(), 5);    // iterador para o 5
    if (it != v.end())
        std::cout << "posição " << it - v.begin() << "\n";   // 1

    int soma = std::accumulate(v.begin(), v.end(), 0);       // 16
    int maior = *std::max_element(v.begin(), v.end());       // 8
    std::sort(v.begin(), v.end(), std::greater<int>());      // decrescente
}
Exercício: o que begin() e end() representam?

begin() aponta para o primeiro elemento; end() aponta para uma posição depois do último (marca o fim).

Aula 26: Lambdas

Uma lambda é uma função criada no próprio lugar de uso: [captura](parâmetros) { corpo }. Dentro dos colchetes você escolhe quais variáveis externas ela enxerga.

#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    auto dobro = [](int x) { return x * 2; };
    std::cout << dobro(4) << "\n";               // 8

    std::vector<int> v = {5, 2, 8, 1, 9};
    int limite = 4;
    int qtd = std::count_if(v.begin(), v.end(),
                            [limite](int x) { return x > limite; });   // 3

    std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; }); // decrescente
}

Capturas: [x] copia x, [&x] usa o original, [=] copia tudo e [&] referencia tudo.

Exercício: o que vai entre [ ] em uma lambda?

A lista de captura: as variáveis externas que a lambda pode usar, por valor ([x]) ou por referência ([&x]).

Aula 27: Smart pointers

Os ponteiros inteligentes de <memory> chamam o delete por você. unique_ptr tem um único dono; shared_ptr conta quantos donos existem e libera quando o último sai.

#include <iostream>
#include <memory>
#include <string>

int main() {
    auto p = std::make_unique<int>(42);       // dono único
    std::cout << *p << "\n";                  // sem delete: libera sozinho

    auto q = std::make_shared<std::string>("C++");
    auto r = q;                               // dois donos
    std::cout << q.use_count() << "\n";       // 2

    // std::unique_ptr<int> b = p;            // ERRO: não pode copiar
    std::unique_ptr<int> b = std::move(p);    // transfere a posse
}

Regra de ouro moderna: evite new e delete soltos. Prefira make_unique, make_shared e os contêineres da STL.

Exercício: quando usar unique_ptr e quando usar shared_ptr?

unique_ptr quando só um dono é responsável pelo objeto; shared_ptr quando vários donos precisam compartilhá-lo.

Aula 28: Templates

Um template é um molde de função ou classe parametrizado por tipo. O compilador gera a versão certa para cada tipo usado. A própria STL (vector<T>, map<K,V>) é feita de templates.

#include <iostream>
#include <string>

template <typename T>
T maior(T a, T b) {
    return (a > b) ? a : b;
}

template <typename T>
class Caixa {
    T valor;
public:
    Caixa(T v) : valor(v) {}
    T get() const { return valor; }
};

int main() {
    std::cout << maior(3, 7) << "\n";          // 7
    std::cout << maior(2.5, 1.5) << "\n";      // 2.5
    Caixa<std::string> c("oi");
    std::cout << c.get() << "\n";
}
Exercício: o que é um template?

Um modelo de função ou classe que funciona com qualquer tipo; o compilador gera a versão adequada para cada tipo usado.

Aula 29: Exceções

Quando algo dá errado, você pode throw (lançar) uma exceção e tratá-la em outro lugar com try/catch, sem misturar o tratamento de erro com o fluxo normal.

#include <iostream>
#include <stdexcept>
#include <string>

double dividir(double a, double b) {
    if (b == 0) throw std::invalid_argument("divisão por zero");
    return a / b;
}

int main() {
    try {
        std::cout << dividir(10, 2) << "\n";   // 5
        std::cout << dividir(1, 0) << "\n";    // lança a exceção
    } catch (const std::exception& e) {
        std::cout << "Erro: " << e.what() << "\n";
    }

    try {
        int n = std::stoi("abc");              // não é número
    } catch (const std::invalid_argument&) {
        std::cout << "não é número\n";
    }
}

Dica: capture por const & e use exceções para situações excepcionais, não para o fluxo normal do programa.

Exercício: o que acontece quando uma exceção é lançada com throw?

A execução sai da função atual e sobe até encontrar um catch compatível; se não houver, o programa termina.

Aula 30: Arquivos

Com <fstream>, std::ofstream escreve em arquivos e std::ifstream lê, usando os mesmos operadores do cout e cin.

#include <fstream>
#include <iostream>
#include <string>

int main() {
    std::ofstream saida("notas.txt");        // cria ou sobrescreve
    saida << "Ana 9\nBeto 7\n";
    saida.close();

    std::ifstream entrada("notas.txt");
    if (!entrada.is_open()) {
        std::cout << "não consegui abrir\n";
        return 1;
    }
    std::string linha;
    while (std::getline(entrada, linha)) {
        std::cout << linha << "\n";
    }
}

Abra um std::ifstream e use while (std::getline(arquivo, linha)).

Aula 31: Projeto final: agenda de contatos

Hora de usar o que aprendeu: struct, vector, funções, referências constantes, laço do-while, getline e string. Compile com g++ -std=c++17 agenda.cpp -o agenda.

#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Contato {
    string nome;
    string telefone;
};

void listar(const vector<Contato>& agenda) {
    if (agenda.empty()) { cout << "Agenda vazia\n"; return; }
    for (const auto& c : agenda)
        cout << c.nome << " - " << c.telefone << "\n";
}

void buscar(const vector<Contato>& agenda, const string& termo) {
    bool achou = false;
    for (const auto& c : agenda) {
        if (c.nome.find(termo) != string::npos) {
            cout << c.nome << " - " << c.telefone << "\n";
            achou = true;
        }
    }
    if (!achou) cout << "Nenhum contato encontrado\n";
}

int main() {
    vector<Contato> agenda;
    int opcao = 0;
    do {
        cout << "\n1) Adicionar  2) Listar  3) Buscar  0) Sair\n> ";
        cin >> opcao;
        cin.ignore();
        if (opcao == 1) {
            Contato c;
            cout << "Nome: ";     getline(cin, c.nome);
            cout << "Telefone: "; getline(cin, c.telefone);
            agenda.push_back(c);
        } else if (opcao == 2) {
            listar(agenda);
        } else if (opcao == 3) {
            string termo;
            cout << "Buscar: "; getline(cin, termo);
            buscar(agenda, termo);
        }
    } while (opcao != 0);
}

Desafios para evoluir o projeto:

  • Ordenar a agenda por nome com std::sort e uma lambda (Aulas 25 e 26).
  • Salvar e carregar os contatos em um arquivo (Aula 30).
  • Criar uma opção para remover um contato com erase (Aula 22).
  • Tratar entradas inválidas com try/catch (Aula 29).
Exercício: por que as funções recebem a agenda como const vector<Contato>&?

Para não copiar o vetor inteiro a cada chamada (referência) e garantir que a função não o altere (const).
