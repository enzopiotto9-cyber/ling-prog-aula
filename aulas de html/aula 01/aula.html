Aula 1: O que é HTML

HTML (HyperText Markup Language) é a linguagem que descreve a estrutura de uma página: o que é título, o que é parágrafo, o que é link. Ele não cuida da aparência (isso é o CSS) nem do comportamento (isso é o JavaScript).

Um elemento HTML é formado por uma tag de abertura, o conteúdo e uma tag de fechamento:

<p>Olá, mundo!</p>

Algumas tags não têm conteúdo e por isso não fecham, como <br> e <img>.

Exercício: qual é a tag de fechamento de <h1>?

É </h1>. A barra indica que o elemento terminou.

Aula 2: Estrutura básica

Toda página HTML começa com este esqueleto:

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Minha página</title>
</head>
<body>
    <h1>Olá!</h1>
</body>
</html>
  • <!DOCTYPE html> avisa o navegador que é HTML5.
  • <html lang="pt-br"> envolve tudo e define o idioma.
  • <head> guarda informações que não aparecem na tela: título da aba, codificação, CSS.
  • <body> guarda o que o visitante realmente vê.
Exercício: onde vai o texto que aparece na aba do navegador?

Na tag <title>, dentro do <head>.

Aula 3: Títulos e textos

Existem seis níveis de título, do mais importante (h1) ao menos importante (h6). Use um único h1 por página.

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Um parágrafo com <strong>destaque forte</strong>
e <em>ênfase</em>.</p>
<br>
<hr>

strong indica importância, em indica ênfase, br quebra a linha e hr desenha uma linha horizontal.

Exercício: escolha o título certo para o nome do site e para uma seção dele

O nome do site vai em <h1> e a seção em <h2>. Escolha pelo significado, não pelo tamanho da letra.

Aula 4: Links e imagens

O link usa a tag a com o atributo href. A imagem usa img com src (o arquivo) e alt (a descrição para quem não vê a imagem).

<a href="aula.html">Ir para as aulas</a>
<a href="https://exemplo.com" target="_blank">Site externo</a>

<img src="./img/gato.jpg" alt="Gato dormindo no sofá">

O alt é obrigatório para acessibilidade e aparece se a imagem não carregar.

Exercício: o que acontece com target="_blank"?

O link abre em uma nova aba.

Aula 5: Listas

Use ul para listas sem ordem, ol para listas numeradas e li para cada item.

<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<ol>
    <li>Abrir o editor</li>
    <li>Criar o arquivo</li>
</ol>

Seu menu de navegação é uma lista ul, estilizada com CSS para ficar na horizontal.

Exercício: qual lista usar para os passos de uma receita?

ol, porque a ordem importa.

Aula 6: Tabelas

Tabelas servem para dados organizados em linhas e colunas, nunca para montar o layout da página.

<table>
    <thead>
        <tr><th>Aula</th><th>Tema</th></tr>
    </thead>
    <tbody>
        <tr><td>1</td><td>O que é HTML</td></tr>
    </tbody>
</table>

tr é uma linha, th é a célula de cabeçalho e td é a célula de dado.

Exercício: qual a diferença entre th e td?

th é cabeçalho (negrito e centralizado por padrão); td é dado comum.

Aula 7: Formulários

Formulários coletam informações. Cada campo deve ter um label ligado ao id do input.

<form action="/enviar" method="post">
    <label for="nome">Nome</label>
    <input id="nome" name="nome" type="text" required>

    <label for="email">E-mail</label>
    <input id="email" name="email" type="email">

    <button type="submit">Enviar</button>
</form>

O atributo type muda o campo (email, password, number, date) e required impede o envio vazio.

Exercício: por que usar label?

Ele descreve o campo para leitores de tela e aumenta a área de clique.

Aula 8: HTML semântico

Tags semânticas dizem o que cada parte da página é, ajudando buscadores e leitores de tela.

<header>...</header>
<nav>...</nav>
<main>
    <section>...</section>
    <article>...</article>
</main>
<footer>...</footer>

Prefira essas tags a div sempre que existir uma que descreva o conteúdo. Esta página usa header, nav, main, section e article.

Exercício: qual tag usar para o menu de links?

<nav>.
