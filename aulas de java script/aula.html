Aula 1: O que é JavaScript

JavaScript é a linguagem de comportamento da web: o HTML cuida da estrutura, o CSS da aparência e o JavaScript do que acontece quando o visitante clica, digita ou rola a página. Ele também roda fora do navegador, com o Node.js.

Ligue um arquivo .js à página com a tag script e use console.log para ver resultados:

<!-- no HTML -->
<script src="app.js" defer></script>

// no arquivo app.js
console.log("Olá, mundo!");
Exercício: onde aparece o resultado do console.log?

No Console das ferramentas do navegador (tecla F12, aba Console).

Aula 2: Variáveis e tipos

Use const para valores que não serão reatribuídos e let para os que mudam. Os tipos básicos são string, number, boolean, null e undefined. Com crases, os template literals inserem variáveis no texto.

const nome = "Ana";
let idade = 25;
idade = 26;
const ativo = true;

console.log(`${nome} tem ${idade} anos`);
console.log(typeof idade);
Exercício: qual a diferença entre let e const?

let permite trocar o valor depois; const não permite reatribuir.

Aula 3: Operadores e condições

Operadores aritméticos: + - * / %. Lógicos: &&, || e !. Prefira === (igualdade estrita) a ==, porque ele não converte os tipos sozinho.

const nota = 7;

if (nota >= 7) {
  console.log("Aprovado");
} else if (nota >= 5) {
  console.log("Recuperação");
} else {
  console.log("Reprovado");
}

console.log(nota >= 5 ? "passou" : "não passou");
Exercício: por que usar === em vez de ==?

Porque ele compara valor e tipo, evitando conversões inesperadas como "5" == 5.

Aula 4: Laços de repetição

Use for quando sabe o número de voltas, while quando depende de uma condição e for...of para percorrer os itens de um array.

for (let i = 1; i <= 3; i++) {
  console.log(i);
}

let n = 3;
while (n > 0) {
  n--;
}

for (const fruta of ["maçã", "uva"]) {
  console.log(fruta);
}
Exercício: qual laço percorre os itens de um array?

O for...of.

Aula 5: Funções

Uma função agrupa um trecho de código para reutilizar. Pode ser declarada com function ou como arrow function (=>), mais curta. return devolve o resultado.

function somar(a, b) {
  return a + b;
}

const dobrar = x => x * 2;

console.log(somar(2, 3));
console.log(dobrar(4));
Exercício: o que faz o return?

Devolve um valor para quem chamou a função e encerra a execução dela.

Aula 6: Arrays e objetos

Um array guarda uma lista de valores, e métodos como push, map e filter facilitam o trabalho. Um objeto agrupa dados com nomes (chave e valor).

const nums = [5, 2, 8, 1];
nums.push(10);

const pares = nums.filter(n => n % 2 === 0);
const dobro = nums.map(n => n * 2);

const pessoa = { nome: "Ana", idade: 25 };

console.log(pares);
console.log(dobro);
console.log(pessoa.nome);
Exercício: o que o map devolve?

Um novo array, com o resultado da função aplicada a cada item.

Aula 7: DOM

O DOM é a página vista como uma árvore de elementos. Com document.querySelector você pega um elemento usando um seletor CSS, e depois altera o texto, as classes ou cria novos elementos.

const titulo = document.querySelector("h1");
titulo.textContent = "Novo título";
titulo.classList.add("destaque");

const li = document.createElement("li");
li.textContent = "Novo item";
document.querySelector("ul").append(li);
Exercício: qual método seleciona o primeiro elemento que combina com um seletor CSS?

O document.querySelector("seletor").

Aula 8: Eventos

Eventos permitem reagir a cliques, digitação e muito mais. Com addEventListener, você diz qual evento escutar e qual função executar quando ele acontecer.

const botao = document.querySelector("button");
botao.addEventListener("click", () => {
  alert("Você clicou!");
});

const campo = document.querySelector("input");
campo.addEventListener("input", e => {
  console.log(e.target.value);
});
Exercício: como executar uma função quando o botão for clicado?

Com botao.addEventListener("click", funcao).
