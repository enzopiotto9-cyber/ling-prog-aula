Aula 1: O que é SQL

SQL (Structured Query Language) é a linguagem usada para consultar e manter dados em bancos relacionais, como MySQL, PostgreSQL, SQLite e SQL Server. Os dados ficam em tabelas, com colunas (os campos) e linhas (os registros).

Nestas aulas usamos uma tabela de exemplo chamada alunos, com as colunas id, nome, cidade e nota. O comando mais importante é o SELECT:

-- Mostra todas as colunas e linhas da tabela
SELECT * FROM alunos;
Exercício: o que o * significa no SELECT?

Todas as colunas da tabela.

Aula 2: SELECT

Liste as colunas que quer ver, separadas por vírgula. DISTINCT remove repetições e AS cria um apelido (alias) para a coluna.

SELECT nome, nota FROM alunos;

SELECT DISTINCT cidade FROM alunos;

SELECT nome AS aluno FROM alunos;
Exercício: para que serve o DISTINCT?

Para não repetir valores iguais no resultado, como cidades duplicadas.

Aula 3: WHERE

O WHERE mantém só as linhas que atendem à condição. Use = <> > < >= <=, AND, OR, IN, BETWEEN, IS NULL e LIKE (o % vale por qualquer texto). Textos vão entre aspas simples.

SELECT * FROM alunos WHERE nota >= 8;

SELECT * FROM alunos
WHERE cidade = 'Recife' AND nota > 7;

SELECT * FROM alunos WHERE nome LIKE 'A%';
Exercício: o que encontra LIKE 'A%'?

Textos que começam com a letra A.

Aula 4: ORDER BY e LIMIT

ORDER BY ordena o resultado (ASC é crescente, o padrão, e DESC é decrescente). LIMIT restringe a quantidade de linhas, ótimo para rankings.

SELECT nome, nota FROM alunos
ORDER BY nota DESC;

SELECT nome, nota FROM alunos
ORDER BY nota DESC
LIMIT 3;
Exercício: como pegar os 3 alunos com as maiores notas?

Com ORDER BY nota DESC LIMIT 3.

Aula 5: Agregações e GROUP BY

Funções de agregação calculam um valor a partir de várias linhas: COUNT, SUM, AVG, MIN e MAX. Com GROUP BY você calcula por grupo, e HAVING filtra os grupos.

SELECT COUNT(*) FROM alunos;

SELECT AVG(nota) FROM alunos;

SELECT cidade, AVG(nota) AS media
FROM alunos
GROUP BY cidade
HAVING AVG(nota) >= 8;
Exercício: qual a diferença entre WHERE e HAVING?

O WHERE filtra as linhas antes de agrupar; o HAVING filtra os grupos depois.

Aula 6: INSERT, UPDATE e DELETE

INSERT adiciona linhas, UPDATE altera e DELETE remove. Cuidado: sem WHERE, UPDATE e DELETE atingem todas as linhas. Teste a condição antes com um SELECT.

INSERT INTO alunos (nome, cidade, nota)
VALUES ('Lia', 'Natal', 9);

UPDATE alunos SET nota = 10
WHERE nome = 'Lia';

DELETE FROM alunos WHERE id = 6;
Exercício: o que acontece com um UPDATE sem WHERE?

Ele altera todas as linhas da tabela.

Aula 7: JOIN

Em bancos relacionais, os dados ficam em tabelas separadas, ligadas por chaves (a chave estrangeira de uma tabela aponta para a chave primária de outra). O JOIN junta essas tabelas em uma consulta, e o ON diz como elas se ligam.

SELECT a.nome, c.titulo
FROM matriculas m
JOIN alunos a ON a.id = m.aluno_id
JOIN cursos c ON c.id = m.curso_id;
Exercício: para que serve o ON no JOIN?

Define a condição que liga as linhas das duas tabelas.

Aula 8: Criando tabelas

Com CREATE TABLE você define as colunas, os tipos e as regras: PRIMARY KEY (identifica cada linha), NOT NULL (obrigatório) e FOREIGN KEY (liga a outra tabela).

CREATE TABLE alunos (
    id INTEGER PRIMARY KEY,
    nome VARCHAR(60) NOT NULL,
    cidade VARCHAR(40),
    nota DECIMAL(3,1)
);
Exercício: o que identifica cada linha de forma única?

A chave primária (PRIMARY KEY).
