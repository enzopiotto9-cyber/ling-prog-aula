Dúvidas frequentes

Preciso saber programar para começar?

Não. As aulas começam do zero, explicando o que é SQL e como fazer sua primeira consulta.

Posso fazer os serviços pelo celular?

Sim. O site funciona no celular, mas para escrever código é mais confortável usar um computador.

Como peço um serviço?

Clique em "Solicitar" no serviço escolhido ou vá direto para a página de Suporte.

Ficou com dúvida? Fale com a gente na página de suporte.
