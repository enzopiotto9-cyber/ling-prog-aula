Aula 1: O que é Python

Python é uma linguagem de programação conhecida pela sintaxe simples e legível. É usada em automação, análise de dados, inteligência artificial, sites e muito mais, e é ótima para quem está começando.

Instale o Python, crie um arquivo ola.py e execute no terminal com python ola.py:

print("Olá, mundo!")
Exercício: como executar o arquivo ola.py?

No terminal, com python ola.py (em alguns sistemas, python3 ola.py).

Aula 2: Estrutura básica

Em Python não há chaves nem ponto e vírgula: a indentação (4 espaços) define os blocos de código. Comentários começam com #, print escreve na tela e input lê o que a pessoa digita.

# isto é um comentário
nome = input("Seu nome: ")
print("Olá,", nome)

if nome:
    print("Nome recebido")
Exercício: como o Python marca onde começa e termina um bloco?

Pela indentação, normalmente com 4 espaços, e não por chaves.

Aula 3: Variáveis e tipos

Não é preciso declarar o tipo: a variável assume o tipo do valor. Os tipos comuns são int, float, str, bool (True ou False) e None. As f-strings inserem variáveis no texto.

nome = "Ana"
idade = 25
preco = 19.90
ativo = True

print(f"{nome} tem {idade} anos")
print(type(idade))
Exercício: o que faz uma f-string?

Insere valores de variáveis dentro do texto, entre chaves: f"Olá, {nome}".

Aula 4: Operadores e condições

Operadores aritméticos: + - * / // % **. Comparação: == != < > <= >=. Lógicos: and, or e not.

nota = 7

if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")
Exercício: qual palavra representa "senão se" em Python?

elif.

Aula 5: Laços de repetição

O for percorre sequências, e o range gera números. O while repete enquanto uma condição for verdadeira.

for i in range(1, 4):
    print(i)

n = 3
while n > 0:
    n -= 1

for fruta in ["maçã", "uva"]:
    print(fruta)
Exercício: o que gera range(1, 4)?

Os números 1, 2 e 3: o final (4) não é incluído.

Aula 6: Funções

Uma função é criada com def. Ela pode ter parâmetros, inclusive com valores padrão, e return devolve o resultado.

def somar(a, b=0):
    return a + b

print(somar(2, 3))
print(somar(5))
Exercício: o que acontece em somar(5) se b=0 for o padrão?

Usa o valor padrão: b vale 0 e o resultado é 5.

Aula 7: Listas e dicionários

A lista guarda itens em ordem e cresce com append. O dicionário guarda pares chave-valor. A list comprehension cria listas de forma curta.

frutas = ["maçã", "uva"]
frutas.append("pera")

pares = [n for n in range(10) if n % 2 == 0]

pessoa = {"nome": "Ana", "idade": 25}

print(pessoa["nome"])
print(len(frutas))
Exercício: como ver quantos itens tem uma lista?

Com len(lista).

Aula 8: Classes e objetos

A classe é o molde e o objeto é criado a partir dela. O método __init__ roda na criação e self representa o próprio objeto.

class Pessoa:
    def __init__(self, nome):
        self.nome = nome

    def falar(self):
        print(f"Oi, sou {self.nome}")

p = Pessoa("Ana")
p.falar()
Exercício: o que é o self?

Uma referência ao próprio objeto, usada para acessar seus atributos e métodos.
