Aula 1: O que é Java

Java é uma linguagem orientada a objetos, tipada e muito usada em sistemas corporativos, aplicativos Android, servidores e bancos. O código é compilado para bytecode e executado pela JVM (Java Virtual Machine), por isso roda em vários sistemas.

Instale o JDK, salve o código em Main.java, compile com javac Main.java e execute com java Main:

public class Main {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
    }
}
Exercício: quais comandos compilam e executam o Main.java?

javac Main.java compila e java Main executa. A JVM roda o bytecode gerado.

Aula 2: Estrutura básica

Todo código Java fica dentro de uma classe, e a execução começa no método main. O nome do arquivo precisa ser igual ao da classe pública. Com import você usa recursos de outros pacotes, como o Scanner, que lê o teclado.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        System.out.print("Seu nome: ");
        String nome = in.nextLine();
        System.out.println("Olá, " + nome);
    }
}
Exercício: que nome deve ter o arquivo de public class Main?

Main.java: o arquivo deve ter o mesmo nome da classe pública.

Aula 3: Variáveis e tipos

Os tipos primitivos mais usados são int, double, boolean e char. String (com S maiúsculo) é uma classe para textos. Com var o Java deduz o tipo, e final impede que o valor mude. O + junta textos.

int idade = 25;
double preco = 19.90;
String nome = "Ana";
boolean ativo = true;
final double PI = 3.14159;
var x = 10;
System.out.println(nome + " tem " + idade + " anos");
Exercício: por que String começa com letra maiúscula?

Porque é uma classe, não um tipo primitivo como int.

Aula 4: Operadores e condições

Operadores aritméticos: + - * / %. Comparação: == != < > <= >=. Lógicos: &&, || e !. Para comparar o conteúdo de textos, use equals, nunca ==.

int nota = 7;

if (nota >= 7) {
    System.out.println("Aprovado");
} else if (nota >= 5) {
    System.out.println("Recuperação");
} else {
    System.out.println("Reprovado");
}

String s = "sim";
if (s.equals("sim")) { /* ... */ }
Exercício: como comparar o conteúdo de duas String?

Com o método equals: a.equals(b).

Aula 5: Laços de repetição

Use for quando sabe o número de repetições, while quando depende de uma condição e o for-each para percorrer arrays e listas.

for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}

int n = 3;
while (n > 0) {
    n--;
}

int[] nums = {4, 7, 9};
for (int x : nums) {
    System.out.println(x);
}
Exercício: qual laço percorre todos os itens de um array?

O for-each: for (int x : nums).

Aula 6: Métodos

Um método tem tipo de retorno, nome e parâmetros. void não devolve nada, e static permite chamar o método sem criar um objeto.

public class Main {
    static int somar(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        int r = somar(2, 3);
        System.out.println(r);
    }
}
Exercício: o que significa void?

Que o método executa algo, mas não devolve valor.

Aula 7: Classes e objetos

A classe é o molde e o objeto é criado com new. O construtor tem o nome da classe. Deixe os campos private e acesse-os por métodos getters e setters (encapsulamento).

public class Pessoa {
    private String nome;

    public Pessoa(String nome) {
        this.nome = nome;
    }

    public String getNome() {
        return nome;
    }

    public void falar() {
        System.out.println("Oi, sou " + nome);
    }
}

Pessoa p = new Pessoa("Ana");
p.falar();
Exercício: por que deixar os campos private?

Para proteger os dados: o acesso passa pelos métodos da classe (encapsulamento).

Aula 8: Coleções

Um array tem tamanho fixo. Já o ArrayList cresce e diminui, e o HashMap guarda pares chave-valor. Elas ficam em java.util; o <Integer> indica o tipo dos itens.

import java.util.*;

List<Integer> nums = new ArrayList<>(List.of(5, 2, 8, 1));
nums.add(10);
Collections.sort(nums);

for (int x : nums) {
    System.out.println(x);
}

Map<String, Integer> idades = new HashMap<>();
idades.put("Ana", 25);
Exercício: qual a diferença entre array e ArrayList?

O array tem tamanho fixo; o ArrayList pode crescer e diminuir.
